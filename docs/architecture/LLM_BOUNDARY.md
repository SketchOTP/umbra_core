# LLM Boundary

## Decision #15

**Accepted:** Optional language layer for communication, summarization, hypothesis generation, and reflection support.  
**Rejected:** LLM as central controller, conscious loop, identity owner, motivation source, memory truth, or existence gate.

Evidence: PROJECT_GOAL; Tracks 3–6 REJECT classifications.

## Allowed (later, non-D-001)

- communication with user
- summarization of already-authorized memory
- hypothesis generation tagged as inference
- reflection assistance that does not authorize

## Forbidden

- own constitutional identity
- write physiology
- set motivation / intrinsic reward as primary will
- grant or modify authority / capabilities
- assert factual memory without provenance as observation
- keep the organism alive (core loop must run with LLM absent)
- execute free text as authority (typed intents only)

## Reflection boundary (decision #13)

Reflection must be: bounded; optional; non-authoritative; evidence-linked; measurable via behavioral improvement (Track 6 ADAPT non-LLM retune). LLM autobiographical diaries do **not** qualify as development.
