# UMBRA-CORE evidence guide

This guide routes technical reviewers through UMBRA-CORE's committed evidence without
turning directory chronology into a scientific narrative. Claims remain bounded to
their cited generation. A later success does not rewrite an earlier failure.

   scientific method, and current frontier.

   and non-goals.
3. [`.agent/CURRENT.md`](../.agent/CURRENT.md) — current governed repository state.

   qualification, compatibility, and integration profile.

to remain understandable without Notion access. Git commits and retained artifacts are

## Tests, experiments, and evidence boundaries

- [`tests/`](../tests/) contains unit, property, regression, governance, and
  experiment-support tests. Names alone do not establish purity; some tests create or
  tick organisms.
- [`experiments/`](../experiments/) contains historical and current harnesses. Execute
  only under the corresponding directive, frozen command, seed, stop, and evidence
  contract.
- [`docs/evidence/`](evidence/) contains committed historical evidence. Some larger or
  create-once runtime artifacts are retained on Atlas and represented here by manifests
  and hashes.
- [`.agent/tasks/`](../.agent/tasks/) contains governed task packets, including
  preregistration, evidence indexes, results, and handoffs for later lineages.
- [`.agent/OUTCOMES.md`](../.agent/OUTCOMES.md) and
  [`.agent/LEARNINGS.md`](../.agent/LEARNINGS.md) are append-only project history, not
  polished public summaries.

## Status vocabulary

- **QUALIFIED** — passed the exact cited evidence contract; scope remains bounded.
- **BOUNDED EVIDENCE** — demonstrated a mechanism or property without a broader
  qualification claim.
- **FAILED** — terminal negative evidence for that generation.
- **UNQUALIFIED** — not demonstrated at the required level.
- **ACTIVE RESEARCH QUESTION** — unresolved and not yet authorized as production
  behavior.

When documentation and code appear to disagree, use the canonical project authority
for intent, Git history/source for implementation, and retained artifacts for observed
behavior. Never infer success from a plan or absence from a summary.
