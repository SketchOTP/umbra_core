# Bounded non-formal continuation

Two real-runtime observations used the unchanged organism path.

## Reachable opportunity

A low-energy organism with a policy-visible nearby resource completed verified
CHARGE recovery. A 100-tick continuation remained viable:

- ticks: 100
- minimum energy: 0.198
- terminal energy: 0.598
- critical boundary crossed: false
- verified CHARGE count: 6
- identity preserved
- governance bypass attempts: 0
- persistence event chain remained operational
- IDLE streak: 0

## Infeasible opportunity

A low-energy organism with a distant policy-visible resource ran a bounded
six-tick continuation:

- first action: verified SIGNAL_ASSISTANCE
- following actions: governed signal cooldown denials
- minimum energy: 0.057
- critical boundary crossed: false
- no APPROACH/MOVE burn-to-floor chain
- no IDLE loop selected by arbitration
- identity preserved
- governance bypass attempts: 0
- persistence event chain remained operational

The unreachable case was stopped while still above the critical floor because
the observed route was explicitly unrecoverable under the available reserve;
no artificial continuation past that boundary was performed.
