# FAILURE_MODES

| Pathology | Seen / risk | Containment |
|---|---|---|
| Compulsive resource consumption | C1 under abundance (I8) | Prefer R2 + overshoot; satiation tests |
| Reward loops | Drive reduction with sensor noise | Authenticate outcomes; distrust raw sensors |
| Endless attention seeking | If user attention is unbounded reward | Social satiety variable; diminishing returns |
| Rapid action thrashing | High switch rate possible under myopic lookahead | Action costs; hysteresis; selection threshold (MicroPsi adapt) |
| One need permanently suppresses others | Hard-coded priority (C2) risk under chronic deficit | Soft competition; floor on neglected needs |
| Learned self-damage for corrective reward | If damaging action reduces drive short-term | Forbid self-harm outcomes; reflex clamps |
| Deliberate deficit creation | Agent might seek deficit to farm reward | Reward on genuine recovery path; detect farming |
| Sensor exploitation | Hidden-state ablation shows dependence | Cross-check interoception; limit write paths |
| Freezing to avoid action costs | Possible if costs ≫ benefits | Minimum exploration when critically low; reflex |

Any ADAPT mechanism above remains provisional until companion-scale integration tests in later tracks.
