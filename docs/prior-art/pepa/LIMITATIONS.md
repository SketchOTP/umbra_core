# PEPA limitations (Track 6)

1. **Public code incomplete** — claimed nav modules unreachable (anonymous.4open 401); Sys2/Sys3 not released as cloneable repos.  
2. **Personality is authored** — Big Five NL descriptions are design inputs, not lived temperament.  
3. **Motivation is LLM-generated** — goals and intrinsic rewards come from Sys3 prompts, not endogenous physiology.  
4. **Fixed skill repertoire** — ~19 discrete actions; “open-ended evolution” is goal-text novelty over a closed motor set.  
5. **Sys3 on cloud** — paper/site show cloud Sys3 with on-robot Sys1/Sys2; organism will is not body-local.  
6. **No license to audit** — unreachable repos ⇒ cannot adopt code.  
7. **Hardware-heavy** — Unitree + arm + LiDAR stack not required for companion kernel selection but gates upstream fidelity.  
8. **Reflection as prose** — autobiographical LLM reports are not sufficient developmental mechanisms for UMBRA.  
9. **Independent repro is abstract** — micro-world qualifies mechanisms; it does not validate PEPA’s robot metrics.  
10. **D-001 still blocked** — Track 6 does not authorize a production UMBRA kernel.
