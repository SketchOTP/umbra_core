# PEPA companion relevance (UMBRA)

## Fits PROJECT_GOAL (adapt / reference)

- Persistent operation without continuous user prompts  
- Embodiment constraints (energy/battery) shaping action  
- Layered goal organization with arbitration  
- Episodic writeback + periodic consolidation (as **bounded** reflection, not LLM diary)  
- Separation of skill execution from deliberation  

## Conflicts with PROJECT_GOAL (reject)

- LLM as Sys3 motivational core and Sys2 deliberative center  
- Authored personality descriptions as the source of individuality  
- Scripted emotional expression actions as “feeling”  
- Treating prompt-stable trait alignment as developmental temperament  
- Claiming open-ended evolution from regenerating LLM goals over a fixed skill set  

## UMBRA boundary

| Borrow | Do not borrow |
|---|---|
| Layering + arbitration + bounded reflection | Big Five constitutional identity |
| Self-preservation skills | LLM intrinsic reward authority |
| Embodiment-aware goal filtering | Cloud Sys3 as organism seat |
| History → preference via memory/learning | Personality prompt A/B as aliveness proof |

Individuality for UMBRA must come primarily from **regulation, embodiment, memory, learning, and lived history** (Tracks 1–5 composition), not from user-authored traits or LLM-generated goals.
