# Identity dissection

| Layer | Hexis manifestation | UMBRA treatment |
|---|---|---|
| D1 Constitutional | agent id, consent/lifecycle, termination flags | Keep hard; **not** memory-editable; **REJECT** self-termination |
| D2 Developed | graph relationships, learned beliefs, drive adjustments from history | **ADAPT** history-dependent preferences/habits |
| D3 Configured | character cards, Big Five seeds, system prompts | **REFERENCE/REJECT as individuality**; presentation only |
| D4 Generated | reflection / “I believe” narratives | **REJECT as authority**; mark inference |

Matched-history experiments show D2 changes behavior; D3-only changes do not.
