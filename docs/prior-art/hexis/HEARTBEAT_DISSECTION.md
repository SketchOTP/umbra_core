# Heartbeat dissection

| Role | Hexis | Independent finding |
|---|---|---|
| Scheduler | `should_run_heartbeat`, workers, scheduled_tasks | Present — time/queue authority |
| Organism trigger | drives / goals / emotional pressure (partial) | Weakly separated from schedule; energy is budget |
| Deliberator | LLM agent loop OODA | **LLM-centered** |
| Effect authority | tool policy / boundaries / energy cost | Present but language-mediated |
| Executor | workers / tools / outbox | Stateless workers |
| Recorder | memories / episodes / audit | DB |

**Conclusion:** Hexis heartbeat is primarily **autonomous scheduling of LLM inference**, not endogenous organism motivation. Action energy is a **computational budget**, not metabolism. No-LLM conditions must fail closed without minting a new identity (Gate 10).
