# Duplication map

The current evidence supports duplication where UMBRA's authority model differs from population or substrate systems. It does not support replacing UMBRA with a prior-art runtime.

| UMBRA responsibility | Prior-art overlap | Classification | Disposition |
|---|---|---|---|
| experiment configuration and repeated execution | MABE2, Evochora plugin/config patterns | PARTIAL_DUPLICATION | refactor internal interfaces after equivalence tests |
| deterministic evidence capture and replay | Evochora full-tick persistence | JUSTIFIED_DUPLICATION | UMBRA replay must include constitutional identity and governed outcomes |
| embodied sensor/control loop | ALIEN, Polyworld | JUSTIFIED_DUPLICATION | external bodies cannot own UMBRA identity or verdicts |
| offline candidate search | ASAL | UNKNOWN | prototype only after holdout/provenance design |
| self-organizing morphology | Lenia, CAX, Ribossome | JUSTIFIED_DUPLICATION | not part of current UMBRA authority model |
| population/genetic evolution | Avida, DISHTINY, Evochora, Aevol, Tierra | JUSTIFIED_DUPLICATION | UMBRA is one persistent individual, not a lineage engine |
| chemistry/protocell substrate | Stringmol, Ribossome | JUSTIFIED_DUPLICATION | explicitly outside project goal |
| constitutional identity and body transfer | no verified equivalent | NO_DUPLICATION | retain as UMBRA-specific requirement |

No `UNJUSTIFIED_DUPLICATION` is established by this pass. That is a finding requiring later source-level comparison, not a presumption that all UMBRA implementations are optimal.
