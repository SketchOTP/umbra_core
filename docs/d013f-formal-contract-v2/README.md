# UMBRA-D-013F

D-013F validates a versioned future P0 recovery evaluator. It does not run a
formal P0, create a formal baseline tag, or change organism behavior.

The change is narrow. A verified, authority-preserving denial caused by
uncertain perception remains visible as a negative experience, but is no
longer equated with immediate viability failure. Genuine authority,
physiology, persistence, and non-adaptive repetition failures remain fail
closed.

Historical D-013D remains `D013D_P0_VIABILITY_FAIL`. The replay result in this
dossier describes only how the new evaluator interprets that frozen trace.
