# Authority path

The relevant real path is:

`perception.py` sensor estimate → `runtime.py` observation dictionaries →
`arbitration.py` recovery reflex → `CHARGE` candidate → governance admission →
`embodiment.py` authoritative resource-distance validation → verified outcome →
`runtime.py` physiology/self-model/world-model learning.

Perception intentionally supplies an estimated distance with confidence and
uncertainty. Arbitration is therefore proposal logic, not authority.
Embodiment uses the authoritative habitat/body state and correctly refuses a
charge outside the execution boundary. Governance does not bypass that
boundary. The negative verified outcome is persisted and passed to the
self-model, including prediction error.

Conclusion: organism authority is preserved end to end. The failure is in the
formal interpretation of this safe denial, not in the authority path.
