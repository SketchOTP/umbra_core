# Data zones

`HISTORICAL_EVIDENCE` is immutable reference; `DISCOVERY_INPUT` is sanitized research data; `DISCOVERY_OUTPUT` contains diagnostic scores/ranks; `CANDIDATE_QUARANTINE` is immutable research-owned output; `VALIDATION_EMBARGO` is unreadable to discovery; `FORMAL_QUALIFICATION` is a separate future operator gate.

Only discovery input → output → quarantine is permitted. Quarantine cannot promote itself to qualification.
