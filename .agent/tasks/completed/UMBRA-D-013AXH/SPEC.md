# UMBRA-D-013AXH specification

The harness must provide deterministic manifest-keyed logical branch IDs,
durable execution/frontier/confirmation/deduplication state, atomic result
publication, fail-closed duplicate handling, worker failure attribution,
restart/rebuild behavior, completeness refusal, bounded concurrency,
parent-termination recovery, and declared retention. The AX protocol must be
byte-semantically preserved and AX scientific branches must remain zero.
