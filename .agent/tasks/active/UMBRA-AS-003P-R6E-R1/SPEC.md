# R6E-R1 scope

R6E-R1 is a zero-organism, analysis-only provenance audit. The historical R6D
matrix and R6E implementation/evidence are immutable. The only accepted root
option construction is `O0 = f(common-root source evidence only)`. Candidate
consequences may change an option status after evaluation, but may not create,
remove, or alter root option identity/support. If a source chain cannot prove a
root option existed before candidate differentiation, the row is rejected and
does not qualify a relation.
