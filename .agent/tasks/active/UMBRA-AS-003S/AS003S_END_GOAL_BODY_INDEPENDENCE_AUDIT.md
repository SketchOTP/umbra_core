# AS-003S end-goal body-independence audit

Verdict: **PASS**.

The bounded replacement transaction preserves the constitutional organism while
changing the active physical embodiment. The retained lifecycle proof keeps the
same `agent_id`, `lineage_id`, birth event, identity commitment, memory, social
state, and individuality state while minting a different `body_instance_id`, a
new SelfModel body binding, and a new active body schema.

## Identity separation

- Constitutional organism identity is unchanged by replacement.
- `body_instance_id` identifies the active physical body relation and changes.
- `body_binding_id` and active `body_schema_id` change with the physical body.
- Attachment generation advances from `1` to `2` for replacement.
- A later compatible profile swap advances generation to `3` while retaining the
  replacement body instance and SelfModel binding/schema distinction.

## Cross-owner coherence

The dedicated `embodiment_body_replaced` event and prospective full snapshot are
committed in one SQLite transaction. Adapter attachment state, Embodiment
occupancy, SelfModel binding/schema, and persistence replay all name the same new
body after commit and restart. Old-generation execution references fail closed.

## Possession and authority boundaries

Replacement is rejected when the old body holds an object; no possession is
teleported or silently rebased. Pending action, delayed proposal, pending world
plan, pending actuation, and PREPARED habitat execution also block replacement.
Governance, Embodiment execution authority, memory, relationships, individuality,
and verified learning are not transferred to an external body authority.

## End-goal disposition

The implementation establishes the required architectural claim: one persistent
organism can survive a true physical-body change without treating a profile swap
as replacement or creating a new constitutional organism. This is bounded body
independence qualification only. It does not qualify modal planning, observer
parity, integrated long-horizon viability, AS-004, or CLOSE-03.
