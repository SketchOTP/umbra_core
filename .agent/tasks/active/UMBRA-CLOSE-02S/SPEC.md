# Scope

The only permitted implementation is a pure, non-production decision-contract
evaluator needed to test the authorized contract fixtures. Production
arbitration, physiology, thresholds, effects, authority, and learning
semantics are immutable during this directive.

Required terminal decision: supported interruptible-intent contract, an
explicit incompatibility/insufficiency result, unresolved multi-intent
authority, or evidence-grounded execution stop.
